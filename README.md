## ⚡ About me

I'm an **AI/ML Engineer** and MSc student in **Telecommunications, AI and Computer Science**, focused on one question: *how do we make computing do more with less energy?*

My work sits where machine learning meets infrastructure: forecasting datacenter load so schedulers can act **before** demand spikes, writing low-power firmware for embedded sensors, and pushing performance per watt on CPUs and GPUs.

- 🔭 **Currently:** predicting CPU spikes in datacenters for proactive, energy-aware workload scheduling
- 🌱 **Focus:** Green AI, efficient training and inference, ML for systems
- 💬 **Ask me about:** ML for infrastructure, CUDA/HPC, networking and V2X
- 📫 **Reach me:** [LinkedIn](https://www.linkedin.com/in/diogo-silva2611/)

## 🚀 Featured projects

| Project | What it does | Stack |
|---|---|---|
| 🔋 [**CPU Spike Predictor**](https://github.com/DiogoZeca/Agentic_AI) | Forecasts CPU spikes on datacenter machines 15–60 min ahead, so a scheduler can defer, migrate or pre-empt work instead of reactively over-provisioning. Trained on Google Cluster Traces (278M rows, 12.5k machines) and transferred **zero-shot** to a production Slurm HPC cluster (PR-AUC up to **0.96**). | Python · XGBoost · Docker |
| 🔌 [**Smart Power Fault Detection**](https://github.com/DiogoZeca/Sensor_Project) | ESP32-C6 sensor node that detects brownouts and power loss at electrical distribution posts in under a second. Light sleep keeps the CPU asleep **50%+** of the time with no impact on detection latency. | C · ESP-IDF · FreeRTOS · MQTT · InfluxDB · Grafana |
| ⚙️ [**DetiCoins**](https://github.com/DiogoZeca/DetiCoins) | SHA-1 miner implemented across scalar, AVX/AVX2/AVX-512, OpenMP, CUDA, OpenCL, MPI and WebAssembly backends to compare throughput across hardware. | C · CUDA · OpenCL · OpenMP · MPI |
| 🛡️ [**UEBA Module for SIEM**](https://github.com/DiogoZeca/UEBAModule_SIEM) | Behavioural analytics that learns traffic baselines and flags anomalous network activity and compromised devices. | Python · Network analysis |
| 🚑 [**Autonomous Emergency Vehicle**](https://github.com/DiogoZeca/Autonomous_Emergency_Vehicle) | V2X testbed where emergency vehicles broadcast alerts, cars clear a corridor and road-side units pre-empt traffic lights. | Python · SUMO · ETSI ITS-G5 · MQTT · Flask |
